## Guidelines compliance: Architecture & Notes

- **One-command pipeline**: `./scripts/run-syntax-demo.ps1 -IncludeInvalid -TraceTokens` (and `sh scripts/run-syntax-demo.sh` on POSIX, plus `Run-Demo.cmd` in the Windows runnable package) runs lexical generation followed by syntax parsing from the saved Symbol Table file in one command.
- **Modular execution**: `ternfold tokens` (lexical producer) and `ternfold parse-table` (syntax consumer) run as separate commands communicating exclusively through the Symbol Table file on disk.
